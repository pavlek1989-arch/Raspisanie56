# Чат-бот расписания для мессенджера МАКС

Бот для учащихся 5–11 классов. Ученик пишет класс (например «5А»), бот присылает актуальное расписание на сегодня: предметы с кабинетами, по номерам уроков. Расписание читается из Google-таблицы школы, где **каждый лист — дата** учебного дня.

## Состав проекта

| Файл | Назначение |
|------|-----------|
| `bot.py` | Flask-приложение: webhook, логика ответов, парсинг ввода класса |
| `max_client.py` | Клиент MAX Bot API (отправка сообщений, подписка webhook) |
| `schedule_parser.py` | Чтение и разбор расписания из Google Sheets |
| `requirements.txt` | Зависимости Python |
| `.env.example` | Шаблон настроек |

## 1. Подготовка расписания в Google Sheets

Таблица уже готова (например «2 четверть 2026-2027.xlsx»). Требования к её структуре:

- **Листы = даты учебных дней**: название вида `18.11.2026`, `05.11.2026` и т.п. Бот находит лист по сегодняшней дате.
- **Внутри листа** — блоки параллелей. В строке-шапке по колонкам идут классы: блок 5-х (5А–5Х), блок 6Р–9Л, блок 10–11-х, блок 6-х, блок 7-х, блок 8-х. Между блоками — ячейка «№ п/п».
- **Данные идут парами строк**: строка предмета, затем строка кабинета (номер кабинета, «спортзал», «актовый зал» и т.д.). Номер урока — число в первом столбце блока.

Например (упрощённо, лист 18.11.2026):

```
 A      | B     | C     | D      | ...
№ п/п   | 5А    | 5Б    | 5В     | ...
1       |       | Англ  | Литер  | ...
        |       | 122   | 225    |   <- кабинеты
2       | ИЗО   | Физра | Матем  | ...
        | 116   | 224   | 120    |   <- кабинеты
```

Бот игнорирует время (ячейки вида `0.\n8.00-8.40`) и показывает только номер урока, предмет и кабинет.

### Дать боту доступ к таблице (без Google Cloud, без сервисного аккаунта)
Бот скачивает книгу `.xlsx` прямо по публичной ссылке, поэтому никаких ключей не нужно. Достаточно:

1. Откройте свою Google-таблицу → **Поделиться**.
2. В поле «Общий доступ» выберите **«Любой, у кого есть ссылка»** → роль **Читатель** → сохраните.
   (Если не хотите открывать всем — можно ограничить конкретными пользователями, но у бота должен быть доступ.)
3. Скопируйте **ID таблицы** из URL: `docs.google.com/spreadsheets/d/<ID>/edit`.

Проверка: откройте в браузере
```
https://docs.google.com/spreadsheets/d/<ID>/export?format=xlsx
```
Если файл скачивается без запроса входа — бот сможет его читать.

## 2. Создание бота в МАКС

1. В поиске МАКС найдите официального бота **`@MasterBot`**.
2. Введите команду `/create`, укажите имя бота — **оно должно заканчиваться на `bot`**.
3. Получите **токен** бота.

## 3. Настройка

```bash
cp .env.example .env
# заполните .env: MAX_TOKEN, MAX_WEBHOOK_SECRET, MAX_WEBHOOK_URL,
# GOOGLE_SPREADSHEET_ID, TIMEZONE
```

Затем:

```bash
pip install -r requirements.txt
python bot.py
```

В режиме разработки можно проверить long polling вместо webhook. Для продакшена нужен **публичный HTTPS-адрес** (вебхуки МАКС требуют валидный TLS).

## 4. Подключение вебхука

1. Разверните бота на сервере (см. ниже) на публичном HTTPS-адресе, например `https://schedule-bot.example.com`.
2. Укажите `MAX_WEBHOOK_URL=https://schedule-bot.example.com/max/webhook` в `.env`.
3. Один раз зарегистрируйте подписку:

```bash
curl -X POST https://schedule-bot.example.com/subscribe
```

Либо вручную:

```bash
curl -X POST "https://platform-api2.max.ru/subscriptions" \
  -H "Authorization: <ВАШ_ТОКЕН>" -H "Content-Type: application/json" \
  -d '{"url":"https://schedule-bot.example.com/max/webhook","secret":"<ОТ_ВАС>"}'
```

После этого МАКС будет присылать события на `/max/webhook` с заголовком `X-Max-Bot-Api-Secret`, который бот проверяет.

## 5. Развёртывание (варианты)

Боту нужен постоянно работающий процесс с публичным HTTPS. Подойдут:

- **VPS** — `pip install gunicorn`, затем
  `gunicorn -w 2 -b 0.0.0.0:8000 bot:app`, перед ним любой reverse-proxy с TLS (nginx/Caddy).
- **Render / Fly.io / Amvera** — подключите репозиторий, укажите команду запуска `gunicorn -w 2 -b 0.0.0.0:8000 bot:app` и впишите переменные окружения из `.env`.
- Тестовый локальный запуск — `python bot.py` (без webhook можно дёргать `get_updates`).

## 6. Кнопки (inline-клавиатура)

Бот отправляет главное меню **с кнопками** для быстрого выбора:

- **Действия:** `Сегодня`, `Завтра`, `Сменить класс`, `Помощь`
- **Классы:** `5А`, `5Б`, `6А`, … (берутся автоматически из заголовков колонок таблицы)

Кнопки реализованы типом `message_button` — они имитируют ввод текста. То есть когда ученик нажимает кнопку `8Б`, бот просто получает текст «8Б» и отвечает расписанием, как если бы ученик написал это вручную. Отдельная обработка callback не требуется.

### Запоминание класса
Бот **запоминает выбранный класс ученика** и не спрашивает его повторно: при запросе «сегодня/завтра/понедельник» сразу показывает расписание сохранённого класса. Класс сохраняется в файл `user_classes.json` и переживает перезапуск бота.

**«Сменить класс»** — забывает сохранённый класс и предлагает выбрать новый (пригодится, если ученик перешёл в другой класс).

При нажатии `Сегодня` / `Завтра` / названия дня, если класс ещё не сохранён, бот показывает **кнопки-классы** для выбора.

Механика кнопок MAX (типы `inline_keyboard`):
- `message_button` — имитирует ввод текста кнопки пользователем.
- `callback_button` — генерирует событие `message_callback` с `callback_data` (требует ответа через `POST /answers?callback_id=...`).
- `link` — кнопка-ссылка.

## 7. Дальнейший процесс действий (по шагам)

Ниже — полный путь от нуля до работающего бота. Выполняйте по порядку.

### Шаг 1. Подготовить Google-таблицу
1. Создайте таблицу, **листы назовите датами** (`18.11.2026`, `19.11.2026`, … — по одному листу на учебный день). Ваша таблица «2 четверть 2026-2027.xlsx» уже подходит.
2. Внутри листа — блоки параллелей: в строке-шапке по колонкам идут классы, между блоками ячейка «№ п/п». Данные — парами строк: предмет, затем кабинет. (См. раздел 1.)
3. Откройте доступ к таблице «по ссылке — Читатель» (см. раздел «Дать боту доступ к таблице»). Бот скачивает книгу `.xlsx` по ссылке — никаких ключей и сервисного аккаунта не нужно.

### Шаг 2. Создать бота в МАКС
1. В `@MasterBot` выполните `/create`, имя бота должно заканчиваться на `bot`.
2. Сохраните токен.

### Шаг 3. Настроить и запустить проект
1. Скопируйте `.env.example` → `.env`, заполните: `MAX_TOKEN`, `MAX_WEBHOOK_SECRET`, `GOOGLE_SPREADSHEET_ID`, `TIMEZONE`.
2. Локально: `pip install -r requirements.txt` → `python bot.py`.
3. Откройте `http://localhost:8000/health` — должно вернуть `{"ok": true, "parser_ready": true}` (если Google-доступ настроен).

### Шаг 4. Проверить расписание без деплоя
Бот умеет работать в режиме long polling. После запуска в диалоге с ботом убедитесь, что он отвечает на запросы класса (см. Шаг 7). Постоянная работа идёт через webhook — переходите к Шагу 5.

### Шаг 5. Развернуть на сервере с HTTPS
Вебхуки МАКС требуют публичный HTTPS-адрес. Варианты:
- **VPS**: `pip install gunicorn`, запуск `gunicorn -w 2 -b 0.0.0.0:8000 bot:app`, перед ним nginx/Caddy с TLS.
- **Render / Fly.io / Amvera**: подключите репозиторий, команда запуска `gunicorn -w 2 -b 0.0.0.0:8000 bot:app`, переменные окружения из `.env`.
- Держите `MAX_WEBHOOK_URL=https://ваш-домен/max/webhook`.

### Шаг 6. Зарегистрировать webhook
Один раз:
```bash
curl -X POST https://ваш-домен/subscribe
```
(или вручную, см. раздел 4). МАКС начнёт присылать события на `/max/webhook`.

### Шаг 7. Протестировать бота
1. В МАКС найдите своего бота, нажмите «Старт».
2. Нажмите кнопку класса → придёт расписание на сегодня.
3. Нажмите `Завтра` → выберите класс → придёт расписание на завтра.
4. Напишите вручную `5Б` → расписание на сегодня.
5. Проверьте нерабочий запрос (например, `привет` без выбора) — должно показать меню.

### Шаг 8. (Опционально) Изменить кнопки / добавить callback-кнопки
Если захотите кнопки с отдельными действиями (например, «Обратиться к завучу»), используйте тип `callback_button` и обрабатывайте событие `message_callback` в вебхуке через `bot.answer_on_callback(callback_id, ...)`. Заготовка для этого уже есть в `max_client.py`.

## 8. Команды бота

| Что пишет/нажимает ученик | Ответ |
|------------------|-------|
| Кнопка `5А` … `11В` | Расписание класса на сегодня |
| `Сегодня` → класс | Расписание на сегодня |
| `Завтра` → класс | Расписание на завтра |
| название дня → класс | Расписание на указанный день |
| `привет` / `помощь` / `/start` / `меню` | Главное меню с кнопками |
| Текст `5А`, `5-А`, `9 б` | Расписание на сегодня |

Класс распознаётся гибко: `5А`, `5-А`, `5 а`, `5а`, `5 "А"` — всё сведётся к `5А`.

## Примечания

- Часовой пояс, по которому определяется «сегодня», задаётся в `TIMEZONE` (по умолчанию `Asia/Yekaterinburg`).
- Бот ищет лист **строго по точной дате** (название листа = `18.11.2026`). Совет: заводите лист на каждый учебный день наперёд, иначе на незаполненный день бот ответит, что расписания нет.
- Если на запрошенную дату нет листа или расписания класса, бот сообщит об этом.
- Для 10-х классов есть разделение `10А инф` / `10А физ` — бот по запросу `10А` вернёт первый найденный вариант.
- Расширение: inline-кнопки для выбора класса/дня — добавляются через `attachments` типа `inline_keyboard` в `max_client.send_message`.

## Автоматическое обновление

Новые листы-даты, добавленные в таблицу, **подхватываются автоматически**: бот кэширует список листов и данные на 5 минут (`cache_ttl`), после чего перечитывает их из Google Sheets. Перезапускать бота не нужно — достаточно, чтобы лист с нужной датой был добавлен в ту же Google-таблицу.

При необходимости кэш можно сбросить принудительно:
```bash
curl -X POST https://ваш-домен/refresh
```
